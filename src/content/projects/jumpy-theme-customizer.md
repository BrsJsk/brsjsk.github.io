If you spend a lot of time in VS Code and use the **Jumpy2 extension**, you already know how
handy it is for zipping around your code. But the colors don't always match the vibe of the rest
of your editor.

I got tired of digging through JSON just to tweak a few values, so I built something to make life
easier. It's a simple, free web app where you can try out different Jumpy2 themes, tweak the
colors, and then copy the JSON straight into VS Code. No login, no setup, no export/import dance.
