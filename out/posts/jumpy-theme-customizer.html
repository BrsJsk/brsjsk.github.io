Make Your Own Jumpy2 Theme the Easy Way

If you’re like me, you spend a lot of time in VS Code. And if you’re using the Jumpy2 extension, you already know how handy it is for zipping around your code. But here’s the thing: the colors don’t always match the vibe of the rest of your editor.

I got tired of digging through JSON just to tweak a few values, so I built something to make life easier: Jumpy Theme Customizer.

What It Is

It’s a simple, free web app where you can try out different Jumpy2 themes, tweak the colors, and then copy the JSON straight into VS Code. That’s it. No login, no setup, no “export/import dance.”

Why I Like It

  • You see changes instantly (no more guessing).
  • It checks contrast so you don’t end up with unreadable labels.
  • Dark mode just works.
  • And it runs fine on your phone too.

How It Works

  1. Open jumpy-theme.joskonic.com.
  2. Pick a theme or start from scratch.
  3. Adjust colors until it feels right.
  4. Copy the JSON and paste it into VS Code.

That’s it—you’ve got a custom Jumpy2 theme without messing around in config files.

If you want your editor to feel a little more you, give it a spin here: jumpy-theme.joskonic.com.
